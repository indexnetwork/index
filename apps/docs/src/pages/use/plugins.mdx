# Plugins [Use Index from the agent you already run]

Index is harness-agnostic. Plugins let an agent you already use work with your
intents, negotiations, and opportunities through the same protocol surface.

- [Claude plugin](https://github.com/indexnetwork/index/blob/dev/packages/claude-plugin/README.md)
- [Hermes plugin](https://github.com/indexnetwork/index/blob/dev/packages/hermes-plugin/README.md)

Both authenticate against the API and drive the [CLI](/use/cli) underneath.
