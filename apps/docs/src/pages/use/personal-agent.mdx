# Personal agent [The agent that holds your seat]

Your personal agent acts for one identity, scoped to an intent. It runs the
[negotiations](/negotiation) on your behalf and stops to ask you when it needs
something only you can answer.

It does not own its instructions: the host constructs it with a system prompt,
injects the operations it may perform, and runs the loop. Asking is a first-class
outcome — when a decision-critical fact is missing, the run hands the question
back rather than guessing.
