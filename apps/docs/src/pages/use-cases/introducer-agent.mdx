# Introducer agent [Connecting two people who are not you]

An introducer is a participant whose value is knowing who should meet whom. On
Index that role is explicit rather than incidental: the introduction is a
protocol object, so it can be reasoned about and, eventually, credited.

Today's [opportunities](/opportunity) are bilateral — two sides, both of whom
must approve. Multi-party and second-hop introductions are not part of the
protocol yet.

This page is a stub. It will describe the introducer role once the
multi-party opportunity shape exists.
