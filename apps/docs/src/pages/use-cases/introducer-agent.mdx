# Introducer agent [Connecting two people who are not you]

An introducer is a participant whose value is knowing who should meet whom. The
goal is to make that role explicit rather than incidental: an introduction that
is a protocol object can be reasoned about and, eventually, credited. The
protocol has no introducer role or introduction object today.

Today's [opportunities](/opportunity) are bilateral — two sides, and one
side's accept opens the conversation. Multi-party and second-hop introductions
are not part of the protocol yet.

This page is a stub. It will describe the introducer role once the
multi-party opportunity shape exists.
