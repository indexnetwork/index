# API [The protocol's HTTP surface]

The hosted API is `https://protocol.index.network`. Requests and responses are JSON. Every path on these pages is under `/api`.

The [CLI](/use/cli), the [MCP](/use/mcp) server, and `@indexnetwork/client` call this API. Command flags, tool names, and the negotiator loop live on those pages. What an [intent](/intent), [network](/network), [negotiation](/negotiation), or [opportunity](/opportunity) means lives with the primitive.

| Resource | Page |
| --- | --- |

| Intents, discovery, opening opportunities | [Intent](/integrate/rest/intents) |

## Authentication

Send one credential.

A session is `Authorization: Bearer <token>`, or `?token=` on the event stream. The token is the web app's JWT or a device session from `index login`. An API key is the `x-api-key` header. Generate it under [Settings → Access](https://index.network/settings?tab=access) (**Generate Key** — copy it then; it is shown once).

If a request carries both, the session is checked first.

An API key acts as you in the product. These routes accept only a session. A key on them returns 403 with `{ "error": "forbidden", "detail": "..." }`:

| Method | Path |
| --- | --- |
| `POST` | `/api/agents` |
| `PATCH`, `DELETE` | `/api/agents/:id` |
| `DELETE` | `/api/auth/account` |
| `GET` | `/api/auth/devices` |
| `POST` | `/api/auth/devices/revoke` |

Intent and opportunity ids accept a UUID or the 8-character short id. `intentId` on `GET /api/negotiations` is a UUID. `agentId` query parameters are UUIDs.

These need no credential: `GET /api/auth/providers`, `GET /api/users/:userId`, `GET /api/networks/public/:id`, `GET /api/networks/share/:code`, and `POST /api/subscribe`.

## Errors

A failure is JSON `{ "error": "..." }` and the HTTP status. A body that fails validation also includes `details`.

| Status | When |
| --- | --- |
| 400 | The body or query is invalid |
| 401 | The credential is missing, expired, or unknown |
| 403 | The caller is authenticated and not allowed, including an API key on a session-only route |
| 404 | The id does not resolve for this caller |
| 409 | The record moved: a settled negotiation, a raced turn, a paused signal |
| 422 | The server read the request and refused it, such as an intent draft it will not admit |
| 503 | Preparation failed and can be retried; answers already sent are kept |

A refused negotiation turn uses the messages on [Negotiations](/integrate/rest/negotiations#refused-turns). Read the negotiation again before the next write.
