# Product language

The interactive web product uses the following terms consistently:

- **Signal** — the current request or offer a person broadcasts to selected networks.
- **Opportunity** — a potential mutually useful connection returned from matching and negotiation. An opportunity is not automatically accepted.
- **Radar** — the signal-scoped view of opportunities and their lifecycle.
- **Warming** — a signal whose background matching or negotiation is still underway.
- **Network** — the membership and context boundary in which signals may be shared and matched.

`intent` remains the internal and API domain identifier, including TypeScript symbols, routes, schemas, payload keys, tool blocks, and telemetry. Interactive web copy presents that concept to people as a **signal**.
